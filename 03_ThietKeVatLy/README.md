# Thiết kế vật lý ngoài (giao diện)

Phần này cần thực hiện bằng Figma hoặc Canva (công cụ thiết kế trực quan) — không thể tạo bằng code, cần bạn tự thao tác. Nội dung cần tạo:

## 1. Giao diện Menu chính
Màn hình sau khi đăng nhập, gồm các nhóm chức năng:
- Quản lý danh mục (Khách hàng / Sản phẩm / Nhà cung cấp / Nhân viên)
- Quản lý nhập hàng
- Quản lý bán hàng
- Quản lý kho
- Báo cáo - thống kê
- Thông tin tài khoản đang đăng nhập / Đăng xuất

## 2. Form nhập liệu — Lập đơn hàng
Gồm:
- Thông tin khách hàng (ô chọn/tìm kiếm khách hàng)
- Bảng danh sách sản phẩm trong đơn: Tên SP, Số lượng, Đơn giá, Thành tiền
- Tổng tiền đơn hàng
- Các nút: Lưu, Hủy, In hóa đơn

## Các bước thực hiện
1. Tạo file thiết kế trên [Figma](https://figma.com) hoặc [Canva](https://canva.com).
2. Thiết kế 2 màn hình trên (có thể phác thảo tay rồi chụp ảnh nếu không dùng Figma/Canva).
3. Xuất ảnh (PNG/JPG) của từng màn hình, lưu vào thư mục này.
4. Lấy link chia sẻ (share link, chế độ "Anyone with the link can view").
5. Dán ảnh + link vào Phần 3 của báo cáo (`04_BaoCao/BaoCao_PhanTichThietKe.docx`), thay các đoạn `[Chèn ảnh...]` và `[Dán link...]`.
