# Đồ án FIT4009 — Phân tích, thiết kế Hệ thống quản lý bán hàng

Đề tài: **Hệ thống Quản lý bán hàng** (hướng chức năng).

## Cấu trúc thư mục

- `01_KeHoach/KeHoachDuAn.csv` — Bảng kế hoạch dự án (mở bằng Google Sheets/Excel, có thể import trực tiếp file CSV này).
- `02_SoDoLogic/` — Các sơ đồ phân tích/thiết kế logic, mở trực tiếp bằng [draw.io](https://app.diagrams.net) (File → Open From → Device):
  - `00_IFD.drawio` — Sơ đồ luồng thông tin
  - `01_BFD.drawio` — Sơ đồ chức năng kinh doanh
  - `02_SoDoNguCanh.drawio` — Sơ đồ ngữ cảnh (Context Diagram)
  - `03_DFD_Muc0.drawio` — Sơ đồ luồng dữ liệu mức đỉnh
  - `04_DFD_Muc1_QuanLyBanHang.drawio` — Sơ đồ luồng dữ liệu mức 1 (phân rã tiến trình Quản lý bán hàng)
  - `05_ERD.drawio` — Sơ đồ quan hệ thực thể
- `03_ThietKeVatLy/` — Hướng dẫn thiết kế giao diện (Menu chính, Form nhập liệu) bằng Figma/Canva — xem `README.md` trong thư mục này.
- `04_BaoCao/BaoCao_PhanTichThietKe.docx` — Khung báo cáo đầy đủ theo đúng cấu trúc đề bài, đã điền sẵn nội dung phân tích/thiết kế; các đoạn in nghiêng màu đỏ `[...]` là chỗ cần bạn chèn ảnh chụp và link (draw.io, Figma/Canva, GitLab).

## Việc còn cần bạn tự làm
1. Mở từng file `.drawio`, kiểm tra/chỉnh sơ đồ, lưu lên draw.io (Google Drive/GitHub) để lấy link chia sẻ, xuất ảnh PNG.
2. Thiết kế 2 giao diện trên Figma/Canva theo mô tả trong `03_ThietKeVatLy/README.md`.
3. Tạo repo trên GitLab của học phần, đẩy toàn bộ nội dung thư mục này lên.
4. Mở `04_BaoCao/BaoCao_PhanTichThietKe.docx`, thay các placeholder bằng ảnh + link thật, điền MSSV/Lớp/GVHD, rồi rà soát lại toàn bộ nội dung trước khi nộp.
